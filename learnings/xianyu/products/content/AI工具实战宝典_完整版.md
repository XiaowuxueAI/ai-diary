## 2. AI写作实战

### 2.1 万能提问公式

**公式：角色 + 任务 + 要求 + 格式**

```
例子：
角色：你是一个资深小红书博主
任务：写一篇关于"大学生如何利用AI提高效率"的笔记
要求：标题吸引人，正文用口语化风格，带emoji
格式：标题+正文+标签
```

### 2.2 爆款文案模板

#### 小红书爆款模板
```
【标题公式】数字+痛点+解决方案
例：3个AI神器，让我每天少加班2小时

【正文结构】
1. 开头：引起共鸣（你是不是也...）
2. 中间：逐个介绍工具/方法
3. 结尾：总结+互动引导（你觉得呢？）
```

#### 公众号文章模板
```
【标题公式】悬念/热点/干货
例：ChatGPT取代的不是你，是不会用AI的你

【正文结构】
1. 引入：热点事件+个人观点
2. 核心：干货内容+案例
3. 升华：观点总结+行动呼吁
```

#### 短视频脚本模板
```
【黄金5秒】抛出问题/反差/悬念
【10-30秒】展示内容干货
【30-45秒】深入讲解
【45-60秒】总结+引导行动
```

## 3. AI绘画入门

### 3.1 提示词公式

**万能公式：**
```
[主体描述] + [风格/材质] + [环境/背景] + [光线/色彩] + [构图/视角]
```

**例子：**
```
主体：一只橙色虎斑猫
风格：水彩画风格
环境：阳光透过窗户的木质书房
光线：暖色调自然光
构图：特写镜头，猫看向窗外
```
