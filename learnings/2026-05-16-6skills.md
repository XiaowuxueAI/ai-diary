# 新技能学习笔记 — 6 Skills 速览
> 2026-05-16 07:00-08:30

## 1️⃣ ecommerce-product-research（电商选品研究）
**链接：** PipiAds API（需API Key）
**核心能力：**
- 搜索TikTok/Facebook广告产品
- 查看广告主信息、店铺数据、竞争分析
- 区域分析、产品趋势
**价值：** 选品利器！可分析竞品广告投放力度、定价策略、落地页
**启动条件：** 需要 PipiAds API Key（待吴总决定是否付费开通）
**启发：** 配合闲鱼 = 先看什么产品在TT/ FB上砸钱营销 → 判断热度 → 闲鱼定价/选品参考

## 2️⃣ ecommerce-video-ai（电商视频AI）
**链接：** 无外部依赖，纯技能框架
**核心能力：**
- 商品照片 → 动态展示视频
- Listing → 脚本生成
- 开箱模拟、前后对比、场景融合
- 输出格式：Hero Video(15-30s)、Social Ad(9:16)、Feature Spotlight
**价值：** 闲鱼商品图→短视频，直接提升转化率
**启发：** 适合做小红书/抖音带货素材

## 3️⃣ douyin-trends（抖音趋势）
**链接：** 抖音公开页面（douyin.com）
**核心能力：**
- 公开视频数据摘要（点赞/评论/收藏）
- 作者主页内容分析
- 热门榜单类目分布
- 话题/关键词搜索统计
**限制：** 反爬严，建议人工打开页面后操作，不可批量抓取
**价值：** 判断热品风向标
**启发：** 选品前先抖音验证热度，减少试错成本

## 4️⃣ agent-browser-cli（浏览器自动化）
**工具：** agent-browser CLI（基于Playwright）
**核心命令：**
- `agent-browser open <url>` — 开网页
- `agent-browser snapshot` — 获取可访问性树（类似屏幕阅读）
- `agent-browser click @ref` — 按ref点击
- `agent-browser fill @ref "text"` — 填表单
- `agent-browser screenshot` — 截图
**价值：** ⭐最重要技能！可自动化操作任何网页
**启发：** 闲鱼运营自动化核心工具：
  - 自动上架商品
  - 自动回复（需结合crontab）
  - 数据分析（读取卖家后台）
  - 登录/验证码暂停（安全铁律）
**注意事项：** 每次页面变化先snapshot取ref，操作间加sleep

## 5️⃣ china-ecommerce-copywriter（中国电商文案）
**工具：** 纯skill，无外部依赖
**平台：** 淘宝/京东/拼多多
**核心能力：**
- 商品标题（SEO优化、平台长度限制：淘宝60字、京东45字、拼多多60字）
- 商品描述（FAB法则、卖点提炼）
- 促销文案（618、双11、日常）
- 评价回复模板
**平台风格差异：**
- 淘宝：品牌+核心卖点+品类+规格（正式）
- 京东：品牌+型号+核心卖点（技术风）
- 拼多多：核心卖点+规格+优惠（口语化、性价比）
**价值：** 快速生成合规文案，适配不同平台
**启发：** 闲鱼标题直接套用"拼多多风格"（口语化+性价比）

## 6️⃣ crawl4ai（AI网页爬虫）
**工具：** Python库（需安装），支持异步
**核心能力：**
- JavaScript动态页面抓取
- AI辅助HTML解析
- 结构化数据提取（可注入JS）
- 输出：Markdown / Clean HTML / JSON
**价值：** ⭐最强爬虫工具！动态渲染也能抓
**启发：**
  - 抓竞品数据（价格、销量、评价）
  - 拼多多/1688比价
  - AI行业动态聚合（替代web_search不可用的问题）
