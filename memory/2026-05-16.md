## 📝 关键经验总结

### 关于浏览器环境
- WSL2 Ubuntu 26.04 不支持 Playwright Chromium
- 手动下载 Chrome for Testing + 提取缺少的系统库（nss, nspr, asound）+ LD_LIBRARY_PATH = 可运行
- agent-browser CLI 可以用 `--executable-path` 和 `--args "--no-sandbox"` 指定自定义Chrome
- 但 WSL2 无桌面，交互式验证（滑块验证码）需要用户干预

### 关于淘宝/闲鱼登录
- 二维码登录需3分钟完成，用户来不及
- 密码登录会触发滑块验证
- 账号体系：淘宝 = 闲鱼

### 关于飞书消息
- 飞书发消息的 content 字段必须是 JSON 字符串
- "post" 类型时，content 需要是 `json.dumps(content_obj)` 后的字符串
- 不能用 --executable-path 两次（daemon 已运行会报错）
- Python 脚本中 subprocess.run 的 curl 默认会卡住 → 必须加 connect-timeout 和 max-time

### 关于工具安装
- pip install --break-system-packages qrcode[pil] ✅
- pip install --break-system-packages zstandard ✅
- apt 无 sudo 权限
- 架构 ar 存档解析：skip magic → 找 data.tar.zst → zstd 解压 → tar 提取
